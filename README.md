## 🔐 Environment Setup

API keys are stored locally in `.env` and are **not committed to GitHub**.

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key_here
```

A `.env.example` file is provided as a template.


## 🚀 Running the Code

Clone the repository:

```bash
git clone <your-repository-url>
cd mayur_ai
```

Install dependencies using UV:

```bash
uv sync
```

Then run the required day's Python file.

For example:

```bash
python week01/day01/main.py
```
